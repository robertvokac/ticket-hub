What it does

Teamwork, from overview to detail

Ticket Hub brings work tracking, collaboration, and installation management together. These are features available in the current project.

TicketsPlanningCollaborationAdministration

01 / Foundation

Tickets

Every piece of work has a stable key, a status, and a history.

Five types, clear hierarchy

Epic, Story, Task, Bug, and Sub-task. A Sub-task belongs to a parent in the same project; a standard ticket can belong to an Epic.

Descriptions and planning

Markdown, checklists, priority, labels, component, Story Points, due date, and assignee.

Ticket lifecycle

Create, edit, clone, move between projects, change type or parent, apply bulk actions, and restore from the recycle bin.

Links and history

Blockers, related tickets, duplicates, and clones. Structured history records field and status changes.

02 / Flow

Planning

Move from a personal view to the project board.

Kanban board

One board per project, columns tied to the fixed workflow, visual WIP limits, and drag-and-drop cards.

Separate backlog

A paginated list of planned work with manual ordering. Backlog tickets stay off the active board.

Personal dashboard

Assigned and watched tickets, upcoming due dates, recent activity, and a concise summary.

Search and filters

Search titles and descriptions. Filter by project, status, type, priority, and more, with quick choices on the board and backlog.

03 / Team

Collaboration

Keep context beside the ticket, where it belongs.

Comments and mentions

A Markdown editor with live preview, @mentions with in-app notifications, and comment reactions.

Attachments

Upload files, place images in Markdown, and preview supported formats. Deleted attachments can be managed in the recycle bin.

Watching and voting

Users can watch or vote on a ticket themselves. Notifications cover assignments, mentions, and comments on watched work.

Work logs

Record time spent, a work date, and a Markdown-supported comment.

04 / Operations

Administration

Control people, access, and data.

Accounts and roles

Administrators create accounts. Viewer, Member, and Admin project roles govern writes, alongside a global administrator role.

API and tokens

A versioned REST API under /api/v1 and personal access tokens support scripts and integrations.

Installation tools

Audit log, active sessions, project archive, ticket CSV export, and backup and restore tools.

Post-V1 additions

Project custom fields, outbound webhooks, and optional SMTP delivery through a durable outbox processed by a separate command.
